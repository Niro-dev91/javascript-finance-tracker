# JavaScript Finance Tracker — 13 Day Learning Journey

A hands-on JavaScript learning project where I built a Finance Tracker
step by step while learning core and modern JavaScript concepts.

## Learning Roadmap

| Day | Topic |
|---|---|
| Day 01 | JavaScript Fundamentals |
| Day 02 | DOM Manipulation |
| Day 03 | Forms & Events |
| Day 04 | CRUD Operations |
| Day 05 | Modern JavaScript / ES6+ |
| Day 06 | JSON & LocalStorage |
| Day 07 | Async JavaScript & Promises |
| Day 08 | REST APIs & Fetch |
| Day 09 | OOP & Prototypes |
| Day 10 | JavaScript Modules |
| Day 11 | Closures, Scope & JavaScript Internals |
| Day 12 | Event Loop & Runtime |
| Day 13 | Final Finance Tracker |

## Final Project Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Search transactions
- Filter by transaction type
- Sort by amount and date
- Calculate income, expenses and balance
- LocalStorage persistence
- Form validation
- ES Modules
- JavaScript Classes
- Error handling
- Responsive UI
